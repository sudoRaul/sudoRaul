## 🧭 About me

> *"The best solution isn't the cleverest one — it's the one the team can build, ship, and maintain."*

I'm a **Full-Stack Developer** and **Higher Technician in Web Application Development**, focused on building and maintaining web applications that run in **real production environments** — from designing the solution to shipping new features.

- 🛠️ &nbsp;I work across the whole stack: **Laravel + PHP** on the back, **Vue.js + TypeScript** on the front.
- 🚀 &nbsp;Comfortable owning a feature end-to-end: solution design → implementation → deploy → maintenance.
- 📚 &nbsp;I treat **continuous learning** as part of the job, constantly exploring new tools, patterns and methodologies.
- 🤝 &nbsp;I value **teamwork**, clear communication, and always looking for the best solution to each challenge.
- 🧩 &nbsp;I care about **clean code, readable architecture and details** that make software pleasant to use *and* to maintain.
